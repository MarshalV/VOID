# 00. Обзор

VOID — семейство потоков поверх libp2p. Смысл закрыт на краях. Середина сводит, хранит непрозрачный конверт и при нескольких независимых руках режет знание пары. Это не новый IP и не сеть смешения.

## Роли

**Участник (peer).** Имеет транспортный ключ libp2p и выведенный из него `PeerId`. Говорит `/void/chat/1.0.0`: `Hello`, затем кадры Double Ratchet. Может публиковать prekey, класть и забирать свой ящик, резервировать Hop, оборачивать кадр в onion.

**Диспетчер (dispatcher).** Тот же тип ключа, в Identify `protocolVersion = "/void/v1"` и `agentVersion`, который начинается с `void-bootstrap-node/`. Дополнительно:

- Kademlia `/void/kad/1.0.0` в режиме сервера;
- Circuit Relay v2: принимает резервацию Hop и строит circuit;
- ящик и каталог prekey на `/void/chat/1.0.0`;
- по желанию onion-hop (дескриптор в Identify, [09-onion.md](09-onion.md));
- обмен списком диспетчеров по `/void-seed/v1` ([08-seed.md](08-seed.md)).

Диспетчер не является сервером чата. Живой `Encrypted` он не расшифровывает и не пересылает как текст. Circuit и ящик — разные пути. Onion — третий.

Участник, у которого нет ни одного диспетчера, в локальной сети может временно держать чужие конверты. Правила выдачи те же, что у диспетчера ([05-envelope.md](05-envelope.md)); потолок ящиков меньше. Как только диспетчер известен, такой участник чужой `Store` не принимает.

## Потоки

| Имя | Кто с кем | Груз |
|-----|-----------|------|
| `/void/v1` | любой узел, Identify | ключ, агент, адреса |
| `/void/chat/1.0.0` | участник ↔ участник или участник ↔ диспетчер | JSON или CBOR `V1Packet` |
| `/void/file/1.0.0` | участник ↔ участник, запасной канал | JSON управления файлом |
| `/void/kad/1.0.0` | узлы DHT | prekey, ящик v3, объявление провайдера |
| `/libp2p/circuit/relay/0.2.0/hop` | участник → диспетчер | резервация |
| `/libp2p/circuit/relay/0.2.0/stop` | участник → диспетчер → участник | circuit |
| `/void-seed/v1` | диспетчер ↔ диспетчер, отдельный TCP | список узлов под AEAD |

Транспорт участников — TCP и Noise, мультиплексор yamux. Имя протокола Noise и кадр yamux задаёт libp2p, не этот каталог. Поверх Noise участники ещё раз закрывают смысл своим ratchet.

## Что обещано и что нет

Закрыт смысл: текст, состав группы, байты файла, внутренности конверта v3. Не обещана невидимость. Один диспетчер видит встречу. Глобальный наблюдатель по времени и размерам склеивает путь. Сто диспетчеров одного оператора считаются одним наблюдателем.

| Наблюдатель | Видит | Не видит |
|-------------|-------|----------|
| Канал до диспетчера | IP, время, размер TCP, `PeerId` после Noise | текст чата, ключи ratchet |
| Диспетчер на Hop | пару `PeerId` circuit, объём и длительность | кадры внутри Noise между этими двумя |
| Диспетчер на ящике | получателя, внешний id, размер бакета, время приёма | отправителя, `kind`, текст (конверт v3) |
| Один onion-hop v2 | соседа «дальше» и один из бакетов 2 / 16 / 64 КиБ | пару целиком и смысл |
| Наблюдатель всего пути | связь входа и выхода по времени и бакету | открытый текст |
| Участник DHT | ключи `/void/prekey/` и `/void/mailbox/` и непрозрачные значения | текст чата: его там нет |
