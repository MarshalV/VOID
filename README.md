# VOID P2P Messenger

VOID — это децентрализованный мессенджер, ориентированный на приватность и безопасность, построенный на базе протокола `libp2p`.

## 🏗 Архитектура системы

### 1. Сетевой уровень (libp2p)
Сообщения идут **напрямую между пирами** (request-response по `/void/chat/1.0.0`), без центрального сервера чата. Используется стек `libp2p`:
- **Транспорт**: TCP / QUIC.
- **Мультиплексирование**: Yamux.
- **Безопасность канала**: Noise.
- **Поиск и маршруты**:
    - **mDNS** — только внутри одной локальной сети (удобство, не «вся Земля»).
    - **Kademlia** — отдельный DHT VOID (`/void/kad/1.0.0`), **не** публичный IPFS. Чтобы узлы на разных континентах находили друг друга в этой таблице, нужны **общие seed-узлы** (bootstrap), которые кто угодно может поднять — это не хранилище переписки, а точка входа в DHT (аналогично torrent-tracker / bootstrap в других P2P-сетях).
- **NAT**: relay-клиент, DCUtR, AutoNAT, UPnP — для прохождения NAT (донастройка relay по адресам при необходимости).

#### Глобальная связь (разные сети и страны)
1. **Прямой набор** — полный `multiaddr` собеседника (кнопка «ПОДКЛЮЧИТЬ»), если известен его публичный или проброшенный порт.
2. **Список bootstrap VOID** (децентрализуемо, много независимых операторов):
   - переменная окружения **`VOID_BOOTSTRAP`**: несколько адресов через **запятую**;
   - или файл **`void-bootstrap.txt`** в каталоге запуска: **одна multiaddr на строку**, часть строки после `#` считается комментарием.

Пример PowerShell:

```powershell
$env:VOID_BOOTSTRAP = "/dnsaddr/example.com/tcp/4001/p2p/12D3KooW..."
cargo run
```

После загрузки списка узел вызывает `kad.bootstrap()` к этим адресам и наполняет **только** VOID DHT.

### 2. Сквозное шифрование (E2EE)
Защита сообщений реализована в `src/crypto.rs` (Signal Protocol):
- **Handshake**: Noise IK (статическая аутентификация).
- **Double Ratchet**: Обеспечивает Forward Secrecy и Post-Compromise Security.
- **SkipKey Storage**: Кэширование до 100 ключей для работы с задержками в P2P.
- **Безопасность памяти**: `zeroize` для затирания ключей в ОЗУ.

### 3. Стек технологий
- **Язык**: Rust.
- **Сеть**: `libp2p`.
- **UI**: `egui` (Темная тема, Neo-glassmorphism).
- **Криптография**: X25519, ChaCha20-Poly1305, BLAKE2b.

## 🚦 Запуск
```powershell
cargo run
```

При первом запуске создаются файлы `void.key` и `vault.bin`. Не передавайте их третьим лицам.
