# VOID P2P Messenger

VOID — это децентрализованный мессенджер, ориентированный на приватность и безопасность, построенный на базе протокола `libp2p`.

## 🏗 Архитектура системы

### 1. Сетевой уровень (libp2p)
Мессенджер работает без центрального сервера, используя стек `libp2p`:
- **Транспорт**: TCP / QUIC.
- **Мультиплексирование**: Yamux.
- **Безопасность канала**: Noise (Noise_XX для соединений libp2p).
- **Поиск пиров**: 
    - **mDNS**: Автоматическое обнаружение в локальной сети.
    - **DHT (Kademlia)**: Поиск пиров в глобальной сети.
- **Обмен сообщениями**:
    - **Gossipsub**: Глобальный чат.
    - **Direct Messaging**: Прямые сообщения между пирами по `PeerId`.

### 2. Сквозное шифрование (E2EE)
Защита сообщений реализована в `src/crypto.rs` (Signal Protocol):
- **Handshake**: Noise IK (статическая аутентификация).
- **Double Ratchet**: Обеспечивает Forward Secrecy и Post-Compromise Security.
- **SkipKey Storage**: Кэширование до 100 ключей для работы с задержками в P2P.
- **Безопасность памяти**: `zeroize` для затирания ключей в ОЗУ.

### 3. Стек технологий
- **Язык**: Rust.
- **Сеть**: `libp2p`.
- **UI**: `egui` (Темная тема, Neo-glassmorphism).
- **Криптография**: X25519, ChaCha20-Poly1305, BLAKE2b.

## 🚦 Запуск
```powershell
cargo run
```

При первом запуске создаются файлы `void.key` и `vault.bin`. Не передавайте их третьим лицам.
